# DELURE — Luxury Perfume Landing Page

A single-page marketing site for DELURE, a luxury perfume brand.

## Tech Stack

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- **Framer Motion** — scroll-driven animations
- **shadcn/ui** — UI primitives (New York style, Radix-backed)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Design

Palette: ivory / beige / black with warm bronze and gold accents.  
Fonts: **Playfair Display** (serif headings) · **Inter** (body).
